# Landing Page – Roadmap.sh Clone

This project is a landing page inspired by [roadmap.sh](https://roadmap.sh/), showcasing web development learning paths in a visually appealing and interactive way.

---

## Features

- Fully responsive design for desktop, tablet, and mobile  
- Modern UI/UX inspired by roadmap.sh  
- Hero section with call-to-action buttons  
- Interactive cards for web development paths  
- Smooth scrolling between sections  
- JavaScript-enhanced interactivity  

---

## Technologies Used

- HTML5  
- CSS3  
- JavaScript  
- Responsive Design (Media Queries)  

---

## Purpose

The main goal of this project is to improve front-end development skills, including:

- Layout and design of modern landing pages  
- Responsive design for all screen sizes  
- Interactive UI elements  
- Practicing HTML, CSS, and JavaScript together in a real-world context
